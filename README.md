# Recolectores iOS App

Recolectores is a mobile application designed to connect waste collectors with users who need to dispose of recyclable materials responsibly.  

The app facilitates the search, acceptance, and management of recycling collection trips through a clean, intuitive interface.

## Features

- **User Authentication**: Login and account registration for collectors.
- **Dashboard**: Quick access to favorites, trip requests, profile settings, and material details.
- **Map Integration**: View nearby collection opportunities using Apple MapKit.
- **Trip Management**: Accept or reject trips with detailed pickup information.
- **Profile Management**: Update collector profile information.
- **Material Guidance**: Educate collectors on the correct recycling processes for various materials.
